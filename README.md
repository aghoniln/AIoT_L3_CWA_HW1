A full-stack, data-driven Taiwan Weather Forecast Web Dashboard integrating **Central Weather Administration (CWA) Open Data API**, **SQLite Database Caching (`data.db`)**, interactive **Plotly charts**, and color-coded **Folium interactive maps**.

Designed and implemented following the **24-Step AIoT Weather App Architecture Roadmap**.

---

## 🌟 Key Features

- **🌐 CWA Open Data API Integration**: Real-time automated data fetching for 1-week forecasts (`F-D0047-091`) and 36-hour forecasts (`F-C0032-001`).
- **🗄️ SQLite Database Architecture (`data.db`)**: Dual-table relational storage for regional (`TemperatureForecasts`) and city-level (`CityForecasts`) weather metrics with `ON CONFLICT REPLACE` anti-duplication logic.
- **📊 Interactive Temperature Trend Line Charts**: Plotly line charts displaying weekly Highest Temperature (`MaxT`) vs. Lowest Temperature (`MinT`).
- **🗺️ Interactive Folium Taiwan Map**: Dynamic four-color geographic visualization based on average temperature thresholds (<20°C 🔵 Blue, 20–25°C 🟢 Green, 25–30°C 🟡 Yellow, >30°C 🔴 Red) with date filter and city popups.
- **📍 Multi-Level Regional & City Filters**: Instant filtering across **北部地區**, **中部地區**, **南部地區**, **東部地區**, and **離島地區** or specific cities/counties.
- **💡 AI Weather Insights & Advice**: Contextual clothing, umbrella, travel, and agricultural weather advice.

## 📋 SQLite Database Schema Design (Poster Step 8 & 9)

### 1. `TemperatureForecasts` (Regional Forecasts)
```sql
CREATE TABLE TemperatureForecasts (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    regionName TEXT NOT NULL,
    dataDate TEXT NOT NULL,
    mint REAL NOT NULL,
    maxt REAL NOT NULL,
    wx TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(regionName, dataDate) ON CONFLICT REPLACE
);
```

### 2. `CityForecasts` (City & County Forecasts)
```sql
CREATE TABLE CityForecasts (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    cityName TEXT NOT NULL,
    regionName TEXT NOT NULL,
    dataDate TEXT NOT NULL,
    mint REAL NOT NULL,
    maxt REAL NOT NULL,
    wx TEXT,
    latitude REAL,
    longitude REAL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(cityName, dataDate) ON CONFLICT REPLACE
);
```

## 🚀 Quick Start Guide

### Prerequisites
Make sure you have **Python 3.10+** installed.

### 1. Clone Repository & Install Dependencies
```bash
git clone https://github.com/aghoniln/AIoT_L3_CWA_HW1.git
cd AIoT_L3_CWA_HW1

pip install -r requirements.txt
```

### 2. Fetch CWA Weather Data & Initialize Database
```bash
python fetch_cwa_data.py
```
*Output:*
> `Initializing database...`  
> `Fetching CWA dataset F-D0047-091...`  
> `Saving 154 city records and 35 regional records to SQLite...`  
> `Data successfully stored in data.db!`

### 3. Verify Database Queries (Poster Step 10)
```bash
python verify_db.py
```

### 4. Launch Streamlit Web App
```bash
python -m streamlit run app.py
```
Open your browser and navigate to **http://localhost:8501**.

## 🔑 API Key Configuration

The application uses CWA Open Data API authorization. By default, the key is configured in `config.py` or can be set via an environment variable:

```bash
# Windows PowerShell
$env:CWA_API_KEY="YOUR_CWA_API_KEY"

# Linux / macOS
export CWA_API_KEY="YOUR_CWA_API_KEY"
```
