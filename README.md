## 🎯 專案目標 (Project Goals)

1. **資料串接自動化**: 串接中央氣象署 Open Data API (`F-D0047-091` & `F-C0032-001`) 實現全台縣市與區域氣象資料自動化抓取。
2. **高效能儲存架構**: 透過 SQLite 資料庫防重覆機制（`ON CONFLICT REPLACE`）實現氣溫預報快取與歷史紀錄檢索。
3. **GIS 地圖與互動圖表**: 結合 Google Maps 底圖技術與動態標籤，提供具視覺吸引力且符合地理事實的天氣圖表。
4. **極致使用者體驗**: 支援全台大區域（北部、中部、南部、東部、離島）與各縣市單獨篩選，並提供 AI 智慧生活與穿搭建議。

## 🌟 Key Features

- **🌐 CWA Open Data API Integration**: Real-time automated data fetching for 1-week forecasts (`F-D0047-091`) and 36-hour forecasts (`F-C0032-001`).
- **🗺️ Google Maps GIS Integration**: Choice of Google Maps Standard Roadmap, Satellite Hybrid, and Terrain tiles with temperature pill badges.
- **🗄️ SQLite Database Architecture (`data.db`)**: Dual-table relational storage for regional (`TemperatureForecasts`) and city-level (`CityForecasts`) weather metrics with `ON CONFLICT REPLACE` anti-duplication logic.
- **📊 Interactive Temperature Trend Line Charts**: Plotly line charts displaying weekly Highest Temperature (`MaxT`) vs. Lowest Temperature (`MinT`).
- **📍 Multi-Level Regional & City Filters**: Instant filtering across **北部地區**, **中部地區**, **南部地區**, **東部地區**, and **離島地區** or specific cities/counties.
- **💡 AI Weather Insights & Advice**: Contextual clothing, umbrella, travel, and agricultural weather advice.

## 📋 SQLite Database Schema Design (Poster Step 8 & 9)

### 1. `TemperatureForecasts` (Regional Forecasts)
```sql
CREATE TABLE TemperatureForecasts (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    regionName TEXT NOT NULL,
    dataDate TEXT NOT NULL,
    mint REAL NOT NULL,
    maxt REAL NOT NULL,
    wx TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(regionName, dataDate) ON CONFLICT REPLACE
);
```

### 2. `CityForecasts` (City & County Forecasts)
```sql
CREATE TABLE CityForecasts (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    cityName TEXT NOT NULL,
    regionName TEXT NOT NULL,
    dataDate TEXT NOT NULL,
    mint REAL NOT NULL,
    maxt REAL NOT NULL,
    wx TEXT,
    latitude REAL,
    longitude REAL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(cityName, dataDate) ON CONFLICT REPLACE
);
```

## 🚀 Quick Start Guide

### Prerequisites
Make sure you have **Python 3.10+** installed.

### 1. Clone Repository & Install Dependencies
```bash
git clone https://github.com/aghoniln/AIoT_L3_CWA_HW1.git
cd AIoT_L3_CWA_HW1

pip install -r requirements.txt
```

### 2. Test Five-Gate Pipeline Scripts
```bash
# Gate 1: API Data Ingestion
python gate1_fetch.py

# Gate 2: Database Storage
python gate2_database.py

# Gate 5: Automated Crawler
python crawler.py
```

### 3. Verify Database Queries (Poster Step 10)
```bash
python verify_db.py
```

### 4. Launch Streamlit Web App (Google Maps Dashboard)
```bash
python -m streamlit run app.py
```
Open your browser and navigate to **http://localhost:8501**.
